## История

- **P1a / P1a.1 · утверждено как рабочая основа.** Seed UI Kit v0.1, уточнения P1a.1 и нативные паттерны диалогов.
- **ADR-001 · Technology Stack v1.0 · утверждено.** Astro, TypeScript, Scoped CSS, CSS Custom Properties, статическая сборка и типизированные данные каталога. React Islands допустимы при необходимости React. Next.js / App Router имеет статус `SUPERSEDED`. Хостинг — отдельное решение перед публикацией.
- **История P1b.** Коммит `ceea7e5` реализовал первый срез. После сравнения `95310d1` с Prototype v4 владелец запросил восстановление композиции.
- **Полный frontend · разработка разрешена.** Последовательность работы — сверка UI Kit, корректировка P1b, истории и каталог, сервисные сценарии, финальная проверка. Художественная приёмка результата остаётся за владельцем.

## Действующие решения

- Prototype v4 задаёт композицию, роль кадров и ключевые действия. По обновлённому порядку HISHAT и история KAMI идут перед каталогом.
- Каталог содержит семь позиций. Шесть галерей используют кандидатные сопоставления. Для седьмой позиции показываются «Фото готовится» и «Описание готовится».
- Inter и Noto Sans Armenian — рабочие гарнитуры. `--color-accent-hishat` — временный токен. Marck Script и Caveat имеют статус `PROPOSED`. Армянский перевод ожидается.
- Цены, размеры, наличие, карточки товаров, рекомендации по уходу и условия сервиса требуют подтверждения. В истории HOVAN публикация полного текста ожидает редакционного допуска. Для истории KAMI ожидается авторский текст.
- Фото, внутренние документы, полные наборы данных и происхождение материалов хранятся вне публичного дерева и сборки. Публичная сборка использует подписанные поля для изображений.
- Корзина, избранное и формы работают как frontend-демо. Запросы и заказы не отправляются, персональные данные не собираются.
